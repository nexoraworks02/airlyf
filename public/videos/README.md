# Videos

- `hero/` — homepage hero panel clips (`hero-vents.mp4`, `hero-furnace.mp4`, `hero-ac.mp4`). Wired up in `src/config/hero-panels.ts`; a panel without a `video` keeps its photo + dust animation.

- `feedback/` — Airlyf customer testimonial clips, watermarked with the Airlyf logo. Add them in `src/config/feedback-videos.ts`; the homepage section stays hidden until then.
